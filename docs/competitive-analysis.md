## Where TypeScript SDK stands today
The TypeScript SDK for ZyndAI Network provides a comprehensive set of tools for building agents and services. It features dual ESM/CJS support, allowing it to work with both `import` and `require`, and is compatible with Node.js >= 18. The SDK includes a CLI for scaffolding projects, running agents and services, and managing identities. Key modules include `ZyndAIAgent` and `ZyndService`, which provide the foundation for building LLM frameworks, reasoning, tool use, and plain functions. The SDK also supports Ed25519 identity, heartbeat, webhook server, x402 payments, and registry.
